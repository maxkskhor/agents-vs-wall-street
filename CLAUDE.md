# Claude instructions

Follow the project rules in `AGENTS.md`, including the authoritative event
documents named there.

## Repository safety

- Never commit or push work directly to `main`.
- Create a feature branch for every change and open a pull request (merge
  request) targeting `main`.
- Never force-push to this repository, including feature branches.
- Do not use `git push --force`, `git push -f`, or
  `git push --force-with-lease`.
